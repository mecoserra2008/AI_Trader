## 23:36 UTC [decision] WS01 design frozen before results
_ws01, audit, fdr, spec_program · H-WS01-1, H-WS01-2, H-WS01-3, H-WS01-4, H-WS01-5, H-WS01-6, H-WS01-7_

WS01 AUDIT design frozen before results (H-WS01-1..7 appended to the registry first).

Snapshot: the first 596 rows of research/hypotheses_results.jsonl (sha256 1be16ba2...b2e0b); rows appended later by other
workstreams are excluded from every WS01 statistic.

Primary statistic per row (one p per row, two-sided), in priority order:
1. If metrics has a sub-dict named after the row's segment, or a 'primary' sub-dict, read keys there first.
2. Raw p: p_raw, p, p_value, pval, p_two_sided.
3. HAC/plain t or z: t_nw, t, t_stat, z, binom_z, dm_t (t_nw preferred). p from Student-t with df = n - 1 when a
   count key exists (n_eff, n_clusters, n_weeks, n_weekends, n_days, n_dates, n_events, n_trades, n_obs, n; smallest
   cluster-like count first), else Normal.
4. Ratio with CI (ratio + ci95/ci90/ci): z = ln(ratio) / se, se = (ln hi - ln lo) / (2 z_level). Difference with CI
   (diff / mean_diff / mean + ci*): z = est / se on the raw scale. Null 1 for ratios, 0 otherwise.
5. Adjusted-only p (p_holm, holm_p): used as is (conservative), flagged.
6. Multi-cell rows (per-asset / per-cell / per-horizon sub-dicts that each carry p or t): Simes combination of the cell
   p-values (a test of 'some cell has an effect'; liberal for 'all cells' claims), flagged.
7. A manual map (id, segment) -> statistic for supports rows the rules above miss, chosen from the registered test /
   success text, never from the value; each mapping documented in the module.
8. Otherwise no statistic: p = 1 in every family (counted, never dropped).

Families: F_all (every row), F_disc (llm_in_sample rows + pooled rows of hypotheses with no llm_in_sample row),
F_hold (clean_holdout rows). BH and BY at q = 0.05 and 0.10 in each. Sensitivities: drop adjusted-only p; one-sided
(p/2) for supports rows; latest row per (id, segment) only.

Claim classification: a hypothesis is a null / bound / equivalence claim if its title or statement matches
'(null)', 'do not', 'does not', 'no edge', 'no leverage', 'not special', 'nothing', 'less than', 'at most', 'rarely',
